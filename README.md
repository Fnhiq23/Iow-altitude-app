# 低空产业协同平台

> 面向低空产业链参与方的任务协同与运营管理平台。先解���跨组织协作、任务可追踪、设备与作业记录可管理的问题；行业能力通过可配置模块逐步扩展。

## 项目现状

当前仓库处于起步阶段，尚无应用源码、依赖清单或自动化测试。因此本仓库先建立产品与技术蓝图，不预设未经验证的技术栈，也不把“所有行业”误解为首版同时满足所有行业。

## 产品原则

1. **先验证问题，再建设平台**：先与真实产业方确认高频、昂贵且可量化的工作流。
2. **安全与合规优先**：平台记录、提示和执行经授权的工作流；不能替代监管审批、飞手判断或经认证的飞控安全机制。
3. **共性做核心，差异做配置/扩展**：任务、组织、设备、记录、权限为候选共性；行业专属数据和流程通过模块适配。
4. **先模块化单体，后按真实瓶颈拆分**：避免在需求和团队边界未验证前引入分布式系统复杂度。
5. **默认可追溯、最小权限、租户隔离**：关键操作有审计记录，客户数据按授权访问。

## 建议的第一步

邀请来自运营/服务商、设备与数据提供方、行业客户、监管或空域协同相关方的代表访谈。选定一个具体的首发作业场景和一个试点客户，再据真实流程确定数据模型、地图/设备集成及交付端形态。

## 当前非目标

- 首版同时覆盖所有低空产业细分行业。
- 在缺乏设备厂商协议和安全认证的情况下直接控制飞行器。
- 自动作出空域审批、适航或合规结论。
- 在业务规模尚未验证时拆成多个微服务。

## 状态

这是产品与架构讨论基线，不代表已经实现的功能。技术栈、法规适用范围、集成商和服务等级需在试点阶段确认。
