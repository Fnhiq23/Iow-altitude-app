# 产品蓝图：低空产业协同平台

## 1. 产品目标

为参与低空作业的组织提供一个可配置的协同工作区，让各方能够围绕作业任务共享必要信息、跟踪状态、管理设备和人员、留存证据与结果，并把异常交给有权限的人处理。

价值假设：减少信息在表格、聊天工具和多个系统间重复流转；提升任务状态可见性与记录完整性；使作业结果能进入客户现有业务流程。以上均是待试点验证的假设，而不是既成事实。

## 2. 从第一性原理拆解

每项低空业务至少要把以下问题讲清楚：

- **谁负责**：任务发起方、运营方、现场人员、审核人员和数据接收方分别是谁？
- **要完成什么**：任务目标、区域、时间窗口、交付物和验收条件是什么？
- **用什么资源**：人员、设备、载荷、服务商和数据源是否具备？
- **是否允许执行**：有哪些组织流程、空域/场地限制、天气条件和安全检查？由谁依据何种权威来源确认？
- **如何证明完成**：状态、轨迹、影像、检查项、异常处理和交付记录如何留存？
- **产生什么价值**：作业成本、耗时、质量或风险是否有可比较的基线？

平台应帮助管理这些信息与流程，不应把未知的规则伪装成自动化结论。

## 3. 用户与利益相关方

“所有产业方”是长期服务���象，不是首版范围。候选角色包括：

- **需求/资产方**：提交巡检、测绘、监测、配送或应急等作业需求，查看进展与结果。
- **运营服务商**：评估需求、编排人员与设备、安排计划、处理异常并交付成果。
- **现场操作人员**：查看任务资料、完成检查项、记录执行情况并上传材料。
- **机队/设备管理者**：管理设备档案、可用状态、维护和相关凭证。
- **安全/合规责任人**：查看适用规则、审批记录、异常和审计信息；依据组织授权及权威信息源作出判断。
- **集成伙伴**：通过受控接口交换任务、设备或结果数据。

监管机构、空域管理单位或其他公共机构是潜在协作方，不能假设其已接入或认可本平台。

## 4. 核心工作流（候选）

1. 组织管理员创建工作区并邀请成员，分配角色。
2. 需求方提交任务需求及位置、时间窗、交付物等信息。
3. 运营方补全方案、分配资源，并完成组织内部审核/准备清单。
4. 授权人员在任务执行前依据适用要求确认是否具备执行条件；平台记录确认人、时间、依据及版本。
5. 现场人员更新任务状态、上传记录和成果，异常进入明确的责任人队列。
6. 需��方验收交付，任务关闭；相关记录可导出或通过授权接口交付。

审批流程、字段、状态和可见范围应可配置，但必须有合理默认值和变更审计。

## 5. MVP 范围

### 必须验证的能力

- 多组织工作区，组织成员与角色权限。
- 任务登记、状态流转、责任人、时间、区域/位置描述、附件和交付物。
- 设备档案与可用状态的基础记录（不假设可直接读取飞控数据）。
- 任务检查清单、异常/事件记录、评论与通知。
- 操作审计、导出、租户间访问隔离。
- 地图展示作为可选的基础体验；地图供应商、许可和数据来源在选定地区后确认。

### 暂不纳入首版

- 对所有行业提供完整的专用业务应用。
- 无人机远程控制、自动航线下发或自动避障。
- 自动判定空域授权、合法性或适航状态。
- 未经明确授权的跨组织数据共享。
- 复杂实时遥测、AI识别、数字孪生或微服务拆分。

## 6. 成功指标（首个试点需建立基线）

不要先承诺未经测量的百分比。试点应记录基线和目标，并至少评估：

- 从需求提交到任务准备完成的时间。
- 任务信息缺失、重复录入或因协作造成的返工次数。
- 任务状态与��果记录的完整率。
- 异常发现到责任人确认/处理的时间。
- 设备档案与维护状态的可用性。
- 试点用户每周活跃使用、任务完成率及持续使用意愿。

业务指标需按具体首发场景定义，避免以登录量替代客户价值。

## 7. 关键假设与待确认问题

在大规模开发前，和试点客户共同确认：

1. 首发行业与具体作业类型是什么？最高频且最痛的一个流程是什么？
2. 购买者、实际操作者和数据接收方分别是谁？预算来自哪里？
3. 现有工具和系统有哪些？数据能否合法、稳定地导入或导出？
4. 任务的空间/时间信息、结果格式、保留期限和跨组织可见性要求是什么？
5. 适用地区的监管要求与责任边界由谁确认？平台要记录哪些确认，不应代替哪些判断？
6. 首版是 Web 管理端优先，还是现场移动端优先？网络不稳定是否是核心约束？
7. 首个试点客户是否同意提供脱敏样本流程，并参与验收？

## 8. 产品原则

- 先完成一个端到端高价值场景，再复用验证过的共性。
- 让任务状态、责任人和下一步动作清晰可见。
- 权限跟随组织关系与数据敏感度；默认不跨租户共享。
- 对关键业务记录保留来源、时���、操作者和修改历史。
- 安全相关提示必须说明来源、时效和责任边界；信息过期或不可用时明确告警，不静默放行。
- 让用户能导出自己的业务记录，减少平台锁定风险。
